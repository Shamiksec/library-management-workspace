RUN IN MYSQL WORKBENCH
1. Install MySQL Server 8.0+ and MySQL Workbench.
2. Open library_management_system.sql and connect to your local server.
3. Execute the script. IMPORTANT: it drops and recreates a database with this name.
4. Refresh SCHEMAS and expand library_management_system.
5. Run report queries one at a time; the setup and sample data are in the same file.
